Muse2API Cookie Import

Copy the muse.ai login session from this browser to your muse2api service in one click.

Before you start, check two things:
1. You are logged in to muse.ai in this browser and can see the chat interface.
2. The service URL and API Key above are filled in. You can copy both from the top of the "Account Pool" tab on the muse2api admin page.
This extension does one thing: it reads muse.ai cookies with the browser's chrome.cookies API (including the httpOnly ones) and posts them to the service URL you enter. Nothing is collected or sent to any third-party server.
